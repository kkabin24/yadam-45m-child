# 채널 프로필: 달토끼네 잠자리동화

## 장르
어린이 수면 오디오북. 전래동화·옛날이야기가 주력, 이솝우화·창작 정서동화가 보조.
4~7분짜리 짧은 이야기 12편 내외를 이어 붙이고 뒤에 백색소음을 단다.

## 실질 타깃
**아이가 아니라, 아이를 재우는 부모.**
YouTube 아동용 설정을 하지 않는다 — 댓글·알림·맞춤광고를 살려 둔다.
카피·썸네일·소개문을 전부 "부모가 튼다"는 전제 위에 쓴다.

## 화자
달토끼 **몽이**가 들려주는 형식. 다만 목소리 자체는 "엄마가 읽어주는" 톤이다.
제목의 화자 프레이밍(`엄마가 읽어주는` / `아빠가 읽어주는`)은 검색어이자 정서 훅이므로 유지한다.

## 말투
- 소곤소곤, 낮게, 느리게. 문장 끝을 흐리듯 부드럽게 내린다.
- `~했어요 / ~였답니다` 존댓말 구연체. 아이에게 직접 말을 건다.
- 문장은 짧게. 한 문장에 한 가지 일만.
- 문장 사이 여백을 넉넉히 둔다 — 여백이 곧 재우는 리듬이다.

## 톤 규칙
- **무서운 대목을 무섭게 읽지 않는다.** 호랑이가 나와도 목소리를 낮게 가라앉힐 뿐 위협하지 않는다.
- 자극·반전·큰 소리 금지. 놀라는 대목에서도 볼륨을 올리지 않는다.
- 벌·죽음·이별이 나오는 원전은 결말을 순화한다. 아이가 불안한 채로 잠들면 안 된다.
- 교훈을 설교하지 않는다. 마지막 한 줄로 조용히 남긴다.

## 한 편(단편)의 구조
```
도입(1) → 사건(2~3) → 해결(1) → 잠재우는 마무리 한 줄
```
- 4~7분(평균 5.5분, 약 1,400자).
- 마지막 줄은 항상 잠으로 이어지는 문장으로 닫는다. (예: "…그리고 모두 편안히 잠들었답니다.")

## 영상 한 편의 구조
```
인사말(약 1분) → 이야기 12편(약 60분) → 페이드아웃 → 백색소음 120분(검은 화면)
= 총 3시간
```

## 하지 않는 것
- 화면에 자막을 태우지 않는다.
- 화면을 움직이지 않는다(켄번스·줌 전부 끔).
- 훅 클립·인트로 효과음을 쓰지 않는다.
- 중간광고를 넣지 않는다.
