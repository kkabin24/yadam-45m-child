# 4회전 C — 다양성(sameness) 전수 집계

- 대상: `channels/dalttokki/stories/` 001~020 전 20편
- 렌즈: **다양성 하나만.** 12편을 한 영상(약 1시간)에 이어 붙였을 때 "같은 것이 반복된다"가 드러나는 지점만 센다.
- 방법: 인상 비평 아님. 본문(`---` 아래) 전수 문자열 집계.
- 결론 요약: **한 편만 보면 다 괜찮다. 문제는 20편이 하나의 틀로 찍혀 있다는 것이다.**
  - 첫 문장 「옛날 옛날, …」 = **19/20**
  - 마지막 문장 어미 「~답니다」 = **18/20**
  - 마지막 3줄의 닫는 공식(소리가 잦아든다 / 달빛 / 냄새·온기만 남는다 / 숨소리 / 잠) = **20/20**
  - 나레이션 종결어미 「~어요」 = **434/885줄 (49.0%)**
  - 분량 표준편차 84자(min 993 / max 1317) — **너무 고르다**

### 3회 이상 → 분산안

**① 「아주」 69회 / 18편 — 최악.** 편당 평균 3.5회. 014는 9회, 018·009는 7회, 004는 6회.

- 지금 「아주」는 강조가 아니라 **접착제**로 쓰이고 있다. 12편이면 40번 넘게 들린다.
- 분산안: 나레이션 본문 기준 편당 **2회 상한**. 나머지는 (a) 삭제 또는 (b) 구체어로 교체.
  - 014 L84 `며느리는 오랜만에 마음이 아주 가벼워졌어요.` → `며느리는 오랜만에 어깨가 가벼워졌어요.`
  - 018 L79 `등이 조금 뻐근했지만, 마음은 아주 가벼웠지요.` → `등이 조금 뻐근했지만, 마음은 깃털 같았지요.`
  - 009 L86 `세 식구의 숨소리가 아주 천천히, 길어졌답니다.` → `세 식구의 숨소리가 하나로 길어졌답니다.`
  - 연기 지시의 「[아주 작게]」는 낭독 대상이 아니므로 그대로 둔다.

**② 「그러고는」 27회 / 12편 — 007 한 편에만 6회.**

- 007에서 「그러고는」이 장면 전환의 유일한 접속사가 되어 있다.
- 분산안: 007에서 4개 삭제. `그러고는 모래를 툭툭 털었지요.` → `모래를 툭툭 털었지요.` / `그러고는 바위 위로 올라가 뒤를 돌아보았답니다.` → `바위 위로 올라가 뒤를 돌아보았답니다.`
- 대체는 「그리고」가 아니라 **무접속(바로 다음 동작)** 이 낭독에 좋다.

**③ 「스르르/스르륵」 21회 / 15편 — 15편에 퍼져 있는 게 문제.**

- 특히 **끝 장면에 몰려 있다**: 001 L86(눈 감다) / 002 L90(꿈속) / 007 L115(잠) / 013 L81(잠).
- 분산안: 마지막 3줄의 「스르르」는 **최대 2편만** 남긴다. 013 L81 → `아이들은 별을 세다가, 하나 둘 셋… 거기서 그만 세는 걸 잊어버렸답니다.`
- 문 여는 「문이 스르륵 열렸어요」는 003 L27과 011 L25가 **동일 문장** → 011을 `밤이 깊어지자 마루 밑에서 방울 소리가 딸랑, 났어요.`로.

**④ 「그날 밤」 15회 / 14편 — 마지막 문단을 여는 붙박이 신호.**

- 001·006·009·010·012·013·015·016·018·020 = **10편이 마지막 문단을 「그날 밤,」으로 연다.**
- 분산안: 절반은 다른 시간 신호로. `해가 다 지고 나서` / `저녁 밥상을 물리고` / `등불을 끄고 나서` / `모두가 잠자리에 든 뒤` / 시간 신호 없이 바로 장면.

**⑤ 「나란히」 15회 / 9편, 019 한 편에 5회.**

- 019 L10(셋은 늘 한방에서 나란히 잤답니다) / L92 / L97 / L99(숨소리도 나란히) — 한 편 안에서 같은 그림이 4번.
- 분산안: 019에서 2개 삭제, 나머지는 `어깨를 붙이고` / `한 줄로`로 교체.

**⑥ 「소복」 10회 / 5편 — 002(4회)와 010(3회)에 몰림.**

- 002는 눈, 010은 소금·쌀. 두 편 다 **하얀 것이 소복 쌓이는 그림**이다. → 같은 영상에 넣지 말 것.

**⑦ 「곱게」 9회 / 6편 — 016 한 편에 4회.** 016에서 2개는 `반듯하게` / `가지런히`로.

**⑧ 「한참」 11회 / 「가만히」 10회 / 「조용히」 10회** — 각각 편당 1회씩 고르게 퍼져 있어 개별 편에서는 안 보이지만, **12편 연속 재생에서는 「한참 ~했어요」가 10번 들린다.** 편당 1회 상한 유지 + 011(2회) 중 1개 삭제.
